用 GitHub 个人访问令牌 (PAT) 登录。所有改动会以 commit 形式保存到你的 GitHub 仓库，自动触发 Cloudflare Pages 重新部署。

怎么拿到 PAT?
1. 打开 GitHub → Settings → Developer settings → Fine-grained tokens
2. Resource owner 选你自己，Repository access 选 Only select repositories，勾选你的网站 repo
3. Repository permissions 里 Contents 设为 Read and write
4. Generate token，复制 `ghp_` 开头的字符串粘到上面

Token 只会存在你的浏览器 localStorage，不会上传到任何服务器。
